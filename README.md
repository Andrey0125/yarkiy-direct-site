# Яркий Директ

**Яркий Директ** — браузерное расширение для специалистов по контекстной рекламе, работающих с Яндекс Директом.

Расширение помогает упростить повседневные задачи, работу с отчётами, аналитикой и рекламными кампаниями.

## Возможности

- Дополнительные инструменты для работы с Яндекс Директом.
- Удобная настройка и построение отчётов.
- Визуализация и анализ данных.
- Автоматизация отдельных повседневных операций.
